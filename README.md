# Auron MVP

**Auron is an early-stage Web3 staking and governance platform built on Ethereum Sepolia testnet.**

The current MVP allows users to:

* Connect a Web3 wallet
* Deposit ETH and receive dETH
* Stake dETH and receive sETH
* View portfolio and staking positions
* Track rewards
* Review transaction history
* Explore analytics
* Participate in governance
* View the staking leaderboard

Auron has moved beyond the initial MVP validation stage and is now entering **full product development**.

---

## Quick Start

The MVP currently runs entirely as a **frontend application**.

**No backend, database, or `.env` setup is required.**

### Requirements

* Node.js **20.x or newer**
* Chrome or another modern browser
* MetaMask, Rabby, Phantom, or TronLink
* Sepolia test ETH if you want to test transactions

You do **not** need real funds.

### 1. Clone the repository

```bash
git clone https://github.com/bitangels-labs/auron-mvp.git
cd auron-mvp
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the application

```bash
npm run dev
```

### 4. Open Auron

Go to:

**http://localhost:3000**

### 5. Connect your wallet

Click **Connect Wallet**, select your wallet, and switch to **Ethereum Sepolia** when prompted.

For the simplest experience, **MetaMask or Rabby** is recommended.

## What to Explore

Once the application is running, feel free to explore it naturally.

Some of the main areas include:

* **Dashboard** — balances, staking overview, and quick actions
* **Deposit / Withdraw** — ETH ↔ dETH
* **Stake / Unstake** — dETH ↔ sETH
* **Portfolio** — positions and protocol allocation
* **Rewards** — rewards tracking
* **History** — transaction activity
* **Analytics** — protocol and personal metrics
* **Governance** — proposals and voting
* **Leaderboard** — staking participation

You don't need to follow a formal testing script.
